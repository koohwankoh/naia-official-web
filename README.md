# NAIA 공식 웹사이트 v3.0 검수 패키지

## 구성
- `index.html`: 랜딩 페이지, menu-driven 7개 상위 메뉴 및 하위 메뉴, 관리자 CMS/상담 CRM
- `admin.html`: 관리자 진입용 동일 단일 파일
- `assets/org_chart_v1_4.jpg`: 수정 조직도 v1.4
- `.github/workflows/deploy.yml`: GitHub Pages 배포 워크플로

## v3.0 변경
- CMS 임시저장 버튼이 게시글 입력값과 본문을 브라우저 로컬 저장소에 저장하며, 같은 브라우저에서 페이지를 다시 열면 복원합니다.
- 화면/관리자 포털/HTML 다운로드에 v3.0 버전을 반영했습니다.
- 상담은 엑셀형 표에서 조회·검색·분류·메모·처리상태 변경이 가능하고 CSV로 내려받을 수 있습니다.

## 저장 및 운영 한계
현재 프로젝트는 정적 HTML이며 `localStorage`에 저장합니다. 사이트 방문자 상담이나 게시글이 서버 DB로 올라가지 않으며, 다른 기기/브라우저와 관리자에게 자동 공유되지 않습니다. CSV는 Excel 호환 형식이고 `.xlsx` 통합문서는 아닙니다. 실운영 전에 서버 DB/API(예: 승인된 Supabase 또는 자체 백엔드), 권한 체계, 개인정보 보관·삭제 정책, 배포 자격정보를 확정해야 합니다.

첨부 원본에 브라우저 코드에서 확인 가능한 임시 관리자 비밀번호와 안내가 포함되어 있었습니다. 이는 실제 인증 수단으로 사용할 수 없으며, 공개 저장소 배포 전 전부 폐기·교체해야 합니다. 정적 클라이언트 코드의 비밀번호 검사는 보안 경계가 아닙니다. 본 패키지는 CEO의 인증/DB 결정 및 보안 검수를 마치기 전 운영 배포 승인본이 아닙니다.

## 로컬 확인
`index.html`을 브라우저에서 열어 랜딩 메뉴와 하위 메뉴를 확인할 수 있습니다. 관리자 글쓰기·상담 제출 동작은 로컬 브라우저 데이터에 한정됩니다. 실제 공개 운영 전에는 승인된 서버 DB와 인증 시스템에 연결해야 합니다.
